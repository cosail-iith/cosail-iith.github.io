Software

Open-source code accompanying the research of CoSAIL and its principal investigator. Most of these packages were developed at ETH Zurich before the lab was founded; CoSAIL’s own releases will be added here. Each package implements the method of a specific paper, together with the examples needed to reproduce its results. If you use one in your work, please cite the paper it accompanies.

Research software

Packages developed by Ankit Gupta at the Department of Biosystems Science and Engineering, ETH Zurich (2012–2026). All are hosted on GitHub.

Python · C++ / CUDA

SpectralKoopman

Implementation of the Spectral Koopman Approximation (SKA) method for stochastic reaction networks. Estimates decay modes, iterated resolvents and Koopman-operator coefficients, and uses them to compute trajectories, parameter sensitivities and cross-spectral densities, with validation against stochastic simulation. Simulation kernels are generated and compiled at runtime; an NVIDIA GPU is optional but accelerates them substantially.

Accompanies: Gupta & Khammash, A spectral framework for revealing the hidden low-dimensional structure in stochastic reaction networks, Nature Communications, 2026.

GitHub Zenodo arXiv GPL-3.0
Python · TensorFlow

DeepCME

A deep learning framework for the chemical master equation. Trains a feedforward neural network to estimate solution statistics of the CME together with their parameter sensitivities, and validates the estimates against Monte Carlo simulation and the Bernoulli path algorithm.

Accompanies: Gupta, Schwab & Khammash, DeepCME: A deep learning framework for computing solution statistics of the chemical master equation, PLOS Computational Biology, 2021.

GitHub
Python

Padé PSD

Monte Carlo estimation of the power spectral density of stochastic reaction networks from an augmented continuous-time Markov chain, using Padé approximants. Compares the estimate with the DFT of sampled trajectories and, where available, the exact spectrum. Examples are configured through a JSON file.

Accompanies: Gupta & Khammash, Frequency spectra and the color of cellular noise, Nature Communications, 2022. See also Padé SSA (IEEE CDC 2022).

GitHub
Python

maxRPA

Scans candidate controller designs for a given controlled biomolecular network and ranks those achieving maximal robust perfect adaptation, in the deterministic homothetic, deterministic antithetic and stochastic antithetic categories, with visualisation and perturbation analysis of the top designs.

Accompanies: Gupta & Khammash, Universal structural requirements for maximal robust perfect adaptation in biomolecular networks, PNAS, 2022. See also An Internal Model Principle for Biochemical Networks (IEEE CSM 2026).

GitHub
C++

tree-and-occurrences

Computes the probability distribution of a reconstructed phylogenetic tree jointly with occurrence data (sampled individuals without sequences), under birth–death sampling models used in phylodynamics.

Accompanies: Gupta, Manceau, Vaughan, Khammash & Stadler, The probability distribution of the reconstructed phylogenetic tree with occurrence data, Journal of Theoretical Biology, 2020.

GitHub

MATLAB

FFSP

Elena D’Ambrosio

The filtered finite state projection method: a finite-dimensional filter for stochastic reaction networks with continuous-time, noise-free observations, obtained by truncating the infinite system of filtering equations with computable error bounds.

Accompanies: D’Ambrosio, Fang, Gupta, Kumar & Khammash, Filtered finite state projection method for the analysis and estimation of stochastic biochemical reaction networks, SIAM Journal on Applied Dynamical Systems, 2026.

GitHub
MATLAB · Jupyter

Rao-Blackwellized CME solver & model identification

Zhou Fang

A divide-and-conquer approach that splits a high-dimensional network into a leader system and conditionally independent follower subsystems, combining Monte Carlo estimation with stochastic filtering to solve the CME and to identify cell-specific models from single-cell data.

Accompanies: Fang, Gupta, Kumar & Khammash, Advanced methods for gene network identification and noise decomposition from single-cell data, Nature Communications, 2024.

MATLAB

Regularized particle filters

Zhou Fang

Particle filters that add artificial noise to particles to mitigate sample degeneracy, with examples on three stochastic reaction networks of different sizes and the conditions under which the filter converges to the exact one.

Accompanies: Fang, Gupta & Khammash, Convergence of regularized particle filters for stochastic reaction networks, SIAM Journal on Numerical Analysis, 2023.

GitHub
MATLAB

Particle filters for multiscale networks

Zhou Fang

Bootstrap particle filters applied to a reduced hybrid model built from the time-scale separations of a multiscale reaction network, which greatly lowers the computational cost of state estimation.

Accompanies: Fang, Gupta & Khammash, Stochastic filtering for multiscale stochastic reaction networks based on hybrid approximations, Journal of Computational Physics, 2022.

GitHub
Python

DoubleBPA

Quentin Badolle

Unbiased Monte Carlo estimation of second-order parameter sensitivities for stochastic reaction networks, extending the Bernoulli path algorithm to second derivatives of expectations with respect to model parameters.

Accompanies: Badolle, Gupta & Khammash, Unbiased estimation of second-order parameter sensitivities for stochastic reaction networks, SIAM Journal on Scientific Computing, 2026.

GitHub
IN DEVELOPMENT

CoSAIL-Markov

A GPU-accelerated computational framework for learning and analysing stochastic Markov dynamics, which will bring together and extend the methods above: massively parallel simulation, learning of probability evolution and stochastic Koopman operators, low-dimensional spectral learning, and controlled dynamics with external inputs and feedback. It will be released on this page under an open-source licence.

Using the code

All packages are free to use for research and teaching. Each repository contains the examples from its paper, so results can be reproduced and the methods adapted to new models. Issues and pull requests are welcome on GitHub.

Code links also appear next to the corresponding entries on the publications page.
